A front door

Opening Mosaic lands on a title card, like powering on a dedicated machine. It's just the recent-projects list, dressed up. Fully keyboard driven.

The logo is the name

The 3×3 mosaic mark scaled to 9× is the only illustration in the app.

Cost: a screen that doesn't exist in take 1. Easy to cut.

No sidebar

The whole screen is the page. Files live one key away (03), like a writing device instead of an IDE.

Pixel headings

H1–H3 render in the bitmap font at 4×, 3×, 2×. Structure is unmistakable without color or markup.

Block gutter

Every block is labelled (H1, ¶, H2…) like line numbers; the caret's block is inverted.

Links

A pixel-dotted underline at rest. Hover inverts the word and shows where it goes.

Key bar

Old-school function-key legend at the bottom, with save state at the right as a floppy icon plus a word.

Cost: a bitmap font is uppercase-only here. A real pixel webfont would be needed so headings keep the writer's actual casing.

Tree as a window

F2 drops a file window over a dithered page, like classic Mac or GEM. The page stays visible behind it, so you don't lose your place.

Box-drawing guides

Hierarchy uses ├─ └─ │ lines, which survive any screen or color.

Unsaved marker

A * in the meta column, nothing color-based.

Cost: an overlay instead of an always-visible tree means one more key press to navigate. That conflicts a bit with the tree being a Kernal feature. Worth deciding.

Floppy as metaphor

Everyone knows the floppy means save. Each state changes the label on the disk (blank, dots, pause bars, X), so the icon alone tells them apart in monochrome.

Failure inverts

Same rule as take 1: the only screaming element is a full inversion.

Hazard band

A pixel-stair stripe across the alert's head. It's the Aperture test-chamber signage in one 14px strip.

Keycaps

Buttons are keycaps with their shortcut printed on them and a hard 4px "travel" shadow. The safe action is filled and focused; discard is set apart.
